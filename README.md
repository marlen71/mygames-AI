# mygames-AI

A collection of small, atmospheric browser games built from simple ideas.

## Games

### [THE LONE PATH](the-lone-path/)
*Small steps. Big silence.*

Short atmospheric top-down mystery in five chapters: wake up in a dark forest, find 5 old notes
(camp, house, quarry, radio tower, foggy lake), search the house interior for what the locked
cabinet is hiding, return to the house and learn what happened. Fully localized (EN/RU/UK via
clickable flags). Pure HTML5 Canvas + JS, zero dependencies, runs from a single folder — even from
`file://`.

**On Windows:** double-click `the-lone-path/PLAY_on_Windows.bat` (or open
`the-lone-path/index.html` directly in Chrome/Edge/Firefox).
