# mygames-AI

A collection of small, atmospheric browser games built from simple ideas.

## Games

### [THE LONE PATH](the-lone-path/)
*Small steps. Big silence.*

Short atmospheric top-down mystery in five chapters: wake up in a dark forest, find 5 old notes
(camp, house, quarry, radio tower, foggy lake), search the house interior, recover three parts
of an old car and drive away from the place. Strict chapter-gated progression, painterly
procedural art, dark-cinematic lighting with a lantern cone that starts in the player's hand.
Look aiming is a choice: the lantern follows your steps or the mouse cursor, with a small reticle in both modes. Story planned as five parts — this game is Part I; parts II–V wait behind a padlock in the
part picker. Locked chapters are also sealed in the world with visible fallen-log barricades.
Fully localized (EN/RU/UK via clickable flags). Pure HTML5 Canvas + JS, zero dependencies,
runs from a single folder — even from `file://`.

**Credits:** game creator — Marlen; screenplay & game design — ChatGPT; game creation — agents Claude & ChatGPT.

**On Windows:** double-click `the-lone-path/PLAY_on_Windows.bat` (or open
`the-lone-path/index.html` directly in Chrome/Edge/Firefox).
