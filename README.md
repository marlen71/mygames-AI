# mygames-AI

A collection of small, atmospheric browser games built from simple ideas.

## Games

### [THE LONE PATH](the-lone-path/)
*Small steps. Big silence.*

Short atmospheric top-down mystery: wake up in a dark forest, find 5 old notes,
learn what happened, return to the cabin. Pure HTML5 Canvas + JS, zero dependencies,
runs from a single folder — even from `file://`.

**On Windows:** double-click `the-lone-path/PLAY_on_Windows.bat` (or open
`the-lone-path/index.html` directly in Chrome/Edge/Firefox).
